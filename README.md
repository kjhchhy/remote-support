# 개인 원격지원 설치

사이트: https://kjhchhy.github.io/remote-support/

Windows 10/11 64비트 사용자가 설치 도우미를 실행하면 RustDesk 공식 최신 **정식** 릴리스를 조회하고 PC 아키텍처에 맞는 설치 파일을 받습니다. 다운로드 크기와 공식 GitHub 릴리스의 SHA-256을 확인한 후 설치합니다. 설치 도우미 자체는 RustDesk를 포함하지 않습니다.

## 적용 설정

| 항목 | 값 |
|---|---|
| ID 서버 | ds307.duckdns.org |
| 릴레이 서버 | 빈 값 (ID 서버가 알려주는 릴레이 사용) |
| Key | 빈 값 |
| API 서버 | 빈 값 |

포트를 따로 지정하지 않아 RustDesk 기본 포트를 사용합니다. 공개키를 생략한 클라이언트가 이 서버에서 연결을 받을 수 있는지는 실제 서버 구성에 따라 확인해야 합니다. Key의 유무를 접속 권한 제어로 간주하지 마세요.

설치 도우미는 고정 비밀번호나 자동 승인 설정을 만들지 않습니다. 기존 RustDesk가 있으면 비밀번호 등 기존 설정을 유지하고 위 네트워크 설정만 바꿉니다. 따라서 기존 PC의 승인 정책은 그대로이며, 기존에 무인 접속이 설정되어 있으면 그것도 유지됩니다. 작업용 관리자 PC에 실행하면 해당 PC의 서버 공개키도 빈 값으로 변경하므로 **지원받을 PC에서만** 실행하세요.

## 사용 흐름

사이트에서 `RemoteSupportSetup.exe` 다운로드 → 파일 실행 → Windows 관리자 권한 승인 → 자동 설치/설정 → RustDesk 자동 실행, 도우미는 5초 후 자동 종료 → 준비 완료 확인 및 ID 전달.

인터넷 접속, .NET Framework 4.x, 관리자 권한이 필요합니다. 32비트 Windows는 지원하지 않습니다. Windows ARM64에는 공식 aarch64 설치 파일을 선택합니다. 설치 도우미는 서명되지 않았으므로 SmartScreen 또는 브라우저의 경고가 표시될 수 있습니다. 조직 정책에 따라 실행이 차단될 수도 있습니다. 웹사이트만으로 설치하거나 권한 승인을 생략하지 않습니다.

이미 설치된 버전이 최신 이상이면 재설치하거나 다운그레이드하지 않습니다. 도우미를 다시 실행할 때 최신 버전을 조회하며, PC에 상시 업데이트 감시 작업을 등록하지 않습니다. 업데이트 중 RustDesk 원격 연결은 끊길 수 있습니다.

프로그램만 남아 있고 Windows 서비스가 없으면 공식 `--install-service` 명령으로 서비스를 복구합니다. 중지된 서비스는 시작합니다. 서비스 복구 중에도 기존 원격 연결이 끊길 수 있습니다. 서비스가 실행되고 네트워크 설정을 다시 읽어 확인한 뒤에만 완료로 표시합니다.

## 빌드 및 배포

Windows PowerShell에서 `./build.ps1`을 실행합니다. 결과는 `dist/RemoteSupportSetup.exe`, `dist/SHA256SUMS.txt`입니다. .NET Framework 기본 C# 컴파일러를 사용하며 외부 패키지는 필요 없습니다.

GitHub Pages는 `main` 브랜치의 `docs/`를 게시합니다. 설치 도우미는 GitHub Releases에 고정 이름 `RemoteSupportSetup.exe`로 게시합니다. 사이트의 다운로드 링크는 항상 최신 **도우미** 릴리스를 가리키며, 도우미가 실행 시점의 최신 **RustDesk**를 공식 저장소에서 가져옵니다.

`v*` 태그를 게시하면 GitHub Actions가 도우미를 빌드하고 테스트한 뒤 릴리스에 실행 파일과 해시를 업로드합니다. 서버 주소나 도우미 코드가 바뀔 때만 새 태그를 만드세요. RustDesk 자체의 업데이트마다 도우미를 다시 빌드할 필요는 없습니다.

## 검증 범위

자동 테스트는 서버 설정 인코딩, 아키텍처 선택, 공식 릴리스 선택, 파일 해시 검증, 버전 비교, 설정 읽기 검증을 확인합니다. GitHub Actions의 일회용 Windows 환경에서 실제 설치와 설정 적용·재실행 검사도 수행합니다. 이때 `support-test.invalid` 시험 주소를 사용해 운영 서버에 시험 PC를 등록하지 않습니다.

설치용 묶음 파일과 설치 후 실행 파일은 다릅니다. 다운로드 파일의 SHA-256만 공식 릴리스와 비교하고, 설치 후에는 버전과 서비스 상태를 확인합니다. `--config` 실행 후 `--option`으로 ID 서버와 빈 릴레이·Key·API 설정을 다시 읽어 기대한 값과 일치할 때만 완료로 표시합니다. 실제 원격접속 성공까지 보장하지 않으므로 대상 PC에서 RustDesk의 ‘준비 완료’를 확인하세요.

오류가 발생하면 설치 창의 ‘오류 기록 보기’에서 자세한 내용을 볼 수 있습니다. 로그는 해당 PC의 임시 폴더에만 저장되며 서버에 전송하지 않습니다.
